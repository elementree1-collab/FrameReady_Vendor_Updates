# FrameReady_Vendor_Updates
a repository for vendor updates spreadsheets for FrameReady Legacy support

Each vendor in FR will have a separate folder.  Each folder will be broken down by when the file was added.  
When you are uploading spreadsheets, please ensure that you place the sheet in the correct folder.

If there are problems with any spreadsheet that has been added to this repository, then please follow up with Candice at rblanchet.support@gmail.com
